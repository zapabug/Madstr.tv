# Audit 2026-11-15 — Mad⚡tr.tv (branch feat/applesauce-revamp, HEAD fbc7e9d + uncommitted tree)

Source of truth used: `feat-applesauce-revamp.md` (the project `AGENTS.md` names it as the spec and calls `docs/` notes from the old NDK app), plus the project `AGENTS.md` rules and the root `/home/jester/Projects/AGENTS.md` process rules. `feat-own-audio.md` was used for the carried-over parts. `docs/Untitled.png` was used as the layout reference.

## Summary
- Spec items checked: 59. **Met 42 / Partial 7 / Missing 3 / Deviates 7.**
- Verify: `pnpm test` PASS (93/93), `pnpm lint` PASS, `pnpm build` PASS with warnings (a stray CSS `*/`, and a 655 kB chunk). A headless Chromium boot of `dist` showed all 8 stickers right away, with no relay gate; the viewer, the 70/30 split and the follow page all render.
- Top 5 risks:
  1. **QR-code login exists, but the spec forbids it.** The spec says "No QR codes any more" (§What zapa said), and §Dropped and R5 list `react-qr-code` and QR as dropped. The code ships `react-qr-code` and a nostrconnect QR login. The spec was never updated.
  2. **Login does not use Applesauce `AccountManager`** (R5, AGENTS.md "Saved logins … Applesauce's AccountManager"). It is a hand-rolled `session.ts`. Cancelling a QR login can still save the session (`accounts.ts:222-223`).
  3. **The split-screen picker is missing its sources/shortcuts column** (§Split screen; R3 "add them right in the viewer"; the 1100 px rule). Source controls were moved onto the home board instead, which breaks "Home is the board and nothing else".
  4. **Process artifacts are missing.** There is no `Status.md`, `build.md` or `planning.md`, so there is no "Undiscussed decisions" log, and about 40 invented numbers and mechanics are unlogged. The spec header is stale ("No code yet", "branch not cut"). R1–R7 are marked `[x]` with no record that the user confirmed them.
  5. **Hard-rule gaps:**
     - Styling work was committed, and is in the uncommitted tree, despite "do not restyle".
     - Text inputs, the seek bar and the mix slider are not `data-nav`, so they cannot be reached from a remote.
     - Profile picture URLs from relays are rendered without an http(s) check (`People.tsx:10`).
